# Changelog

All notable changes to CrateClean are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [Unreleased]

The first public release will be 0.1.0.

### Added

- Project docs, decision records and contribution workflow.
- Project skeleton: the `crateclean` packages, a test suite with generated audio fixtures, and a PyInstaller build of an empty app window.
- Tag round-trip tests for MP3 (ID3v2.3 and v2.4), FLAC and M4A, and the engine's tag loading and saving, which keep each file's tag version, multi-value separators, ID3v1 footer and DJ-software data.
